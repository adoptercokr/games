# 🎮 Project: Emoji Survivor: Code Rush

## 1. Overview
- **Title**: Emoji Survivor: Code Rush
- **Genre**: Roguelike Survivor (Bullet Hell)
- **Platform**: Web (Desktop & Mobile Responsive)
- **Tech Stack**: HTML5 Canvas, Vanilla JavaScript

## 2. Core Gameplay Loop
1. **Move**: The player moves a character (🚀) to avoid enemy emojis (👾, 🕷️, 🐍).
2. **Attack**: The player automatically fires projectiles (⚡) at the nearest enemy.
3. **Collect**: Defeated enemies drop "Code Fragments" (💎).
4. **Upgrade**: Collecting enough fragments triggers a level-up, allowing the player to choose a new ability or upgrade an existing one.

## 3. Key Features (MVP)
- **High Performance**: Smooth 60 FPS gameplay using optimized Canvas 2D API.
- **Juicy Feedback**: 
  - Screen shake on enemy death.
  - Floating damage numbers.
  - Visual particle effects.
- **Progressive Difficulty**: Enemies get faster and more numerous over time.

## 4. Development Plan
- **Phase 1**: Basic setup, Player movement, and Enemy spawning. (Active)
- **Phase 2**: Projectile system and Collision detection.
- **Phase 3**: Experience points and Level-up UI.
- **Phase 4**: Game Over/Restart loop and Sound effects.

## 5. Visual Assets
- **Player**: 🚀 (Emoji-based)
- **Enemies**: 👾, 🕷️, 🐍, 🦂
- **Projectiles**: ⚡, 🔥, ❄️
- **Background**: Dark techno grid (Canvas drawn)
