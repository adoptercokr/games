# 🍪 쿠키런 스타일 러닝 게임 기획서

## 프로젝트 개요
- **게임명**: 쿠키 대탈주 (Cookie Escape!)
- **장르**: 사이드-스크롤 엔드리스 러너
- **타겟**: 초등학생 (7~13세)
- **플랫폼**: 모바일 브라우저 + PC 브라우저 (반응형)
- **엔진**: Phaser.js 3.x (CDN)

---

## 핵심 게임루프 (Core Loop)
달린다 → 장애물 피하기 → 아이템 수집 → 점수 갱신 → 죽음 → 더 멀리 가고싶다!

---

## 캐릭터 시스템
### 기본 캐릭터 (5종)
1. 🍪 **쿠키 용사** - 기본형 (속도 보통, 점프력 보통)
2. 🍓 **딸기 쿠키** - 점프력 +20% (가벼운 타입)
3. 🍫 **초코 쿠키** - 점수 보너스 +10% (튼튼한 타입)
4. 🧁 **컵케이크 쿠키** - 자석 효과 (아이템 자동흡수)
5. 🌙 **달빛 쿠키** - 슬라이드 무적 (특수능력)

### 펫 시스템 (3종)
- 🐶 **빵 강아지**: 금화 +5% 자동 수집
- 🐱 **크림 고양이**: 3초마다 방어막 충전
- 🐨 **쿠키 곰**: 장애물 한 번 파괴 가능

---

## 장애물 시스템
| 타입 | 설명 | 회피방법 |
|------|------|---------|
| 🪨 바위 | 지상 장애물 | 점프 |
| 🌵 선인장 | 낮은 지상 장애물 | 슬라이드 |
| 🦅 독수리 | 공중 장애물 | 슬라이드 or 낮게 달리기 |
| 🔥 불기둥 | 고/저 교차 장애물 | 타이밍 점프 |
| 🍄 버섯 폭탄 | 폭발 반경 장애물 | 멀리 점프 |

---

## 아이템 시스템
| 아이템 | 효과 | 지속 |
|--------|------|------|
| ⭐ 별사탕 | 점수 +50 | 즉시 |
| 🛡️ 방어막 | 장애물 1회 무적 | 5초 |
| 🚀 로켓 | 속도 +50%, 무적 | 3초 |
| 🧲 자석 | 주변 아이템 흡수 | 8초 |
| ⏰ 슬로우 | 장애물 속도 -50% | 5초 |
| 💰 금화 | 캐릭터 해금 재화 | 즉시 |

---

## 점수 시스템
- 기본: 1초당 +10점 (속도 비례 증가)
- 별사탕: +50점
- 100m 돌파 기념: 보너스 점수
- 콤보: 연속 아이템 5개 획득 시 2배
- 베스트 스코어 로컬 저장

---

## 레벨/난이도 곡선
- 0~30초: 튜토리얼 구간 (장애물 느리게, 간격 넓게)
- 30초~2분: 일반 구간 (표준 속도)
- 2분 이후: 하드 구간 (속도 UP, 복합 장애물)
- 5분 이후: 전설 구간 (최고 속도, 모든 장애물 등장)

---

## UI/UX 설계
### HUD (인게임)
- 상단 좌: 현재 점수 (크게)
- 상단 우: 베스트 스코어
- 하단 좌: 생명력 (하트 3개)
- 하단 우: 액티브 아이템 타이머

### 메뉴 화면
- 게임 타이틀 + 로고 애니메이션
- Play 버튼 (크고 화사하게)
- 캐릭터 선택 버튼
- 상점 버튼 (금화로 캐릭터 해금)
- 랭킹 버튼 (로컬)

### 게임 오버 팝업
- 최종 점수 (숫자 카운팅 애니메이션)
- 베스트 스코어 갱신 시 축하 연출
- 재도전 / 메뉴로 / 캐릭터 선택 버튼

---

## 기술 스택
- **렌더링**: Phaser.js 3.x (Canvas/WebGL 자동전환)
- **해상도**: 480×854 기준, 반응형 스케일
- **목표 FPS**: 60 FPS 안정적 유지
- **오디오**: Web Audio API (절차적 생성)
- **저장**: localStorage (베스트스코어, 보유 캐릭터, 금화)
- **PWA**: manifest.json + service worker 호환 구조
