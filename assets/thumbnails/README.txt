========================================================================
🎬 스파크 게임즈(Spark Games) - 움직이는 GIF 게임 배너 등록 가이드
========================================================================

스파크 게임즈 포털은 단순한 정지 이미지가 아닌, 
실제 게임 플레이가 살아 움직이는 "움직이는 GIF 배너" 시스템을 지원합니다!
이를 통해 방문자가 사이트에 오자마자 살아 숨 쉬는 정통 오락실 감성을 느낄 수 있으며,
클릭률(CTR)과 체류 시간이 비약적으로 상승하게 됩니다.

------------------------------------------------------------------------
1. 권장 규격 및 비율 (Optimal Sizes)
------------------------------------------------------------------------
스파크 게임즈의 모든 카드와 배너는 가로세로 비율 "16:11"을 따릅니다.
GIF 배너 제작 시 아래의 규격 중 하나로 제작하셔야 화면 찌그러짐 없이 완벽하게 들어맞습니다.

* 640 x 440 픽셀 (강력 추천!)
  - 모바일 로딩 속도와 화질의 균형을 유지하는 최적의 사이즈입니다.
* 800 x 550 픽셀 (고화질 선명)
  - 보다 고화질의 선명한 품질을 유지하고 싶을 때 적합합니다.

💡 [핵심 최적화 팁]
- 파일 용량: 한 장당 1.5MB 이하 권장 (최대 2.5MB 이하)
  - 10개의 움직이는 GIF가 모바일 메인 화면에서 동시에 로드되므로, 용량이 너무 크면 데이터 소모가 크고 로딩이 버벅거릴 수 있습니다.
- 프레임 레이트 (FPS): 10 ~ 15 FPS 권장
  - 초당 프레임을 약간 낮추면 용량이 절반으로 줄어들면서도 부드러움은 유지됩니다.
- 색상 최적화: 128색 또는 256색 제한
- 루프 설정: 반드시 "무한 루프(Infinite Loop / Loop Forever)"로 세팅해 주세요.

------------------------------------------------------------------------
2. 추천 GIF 캡처 및 제작 도구 (Free Tools)
------------------------------------------------------------------------
* ShareX (Windows용 완전 무료 오픈소스 - 초강력 추천!)
  - 단축키 하나로 화면의 특정 영역(게임 화면)을 마우스 드래그하여 즉시 GIF 파일로 캡처 및 저장해 줍니다. 
  - 설정에서 FPS 및 화질 비율을 아주 쉽게 제어할 수 있습니다.
* ScreenToGif (Windows용 무료 - 사용법 초간단)
  - 가볍고 세련된 인터페이스로 원하는 프레임을 선택하여 GIF로 저장해 줍니다.
* Ezgif.com (웹 브라우저 온라인 도구)
  - 별도 설치 없이 캡처된 동영상이나 정지 이미지들을 올려서 결합, 자르기, 용량 최적화(GIF Compressor)를 진행해 주는 무료 사이트입니다.

------------------------------------------------------------------------

------------------------------------------------------------------------
4. 하이브리드 자동 Fallback 작동 원리
------------------------------------------------------------------------
만약 특정 게임의 .gif 파일이 아직 준비되지 않아 폴더에 없더라도 괜찮습니다!
웹사이트의 스마트 로더가 폴더 안을 검사한 뒤:
- 이미지 파일(.gif)이 있을 경우: 실제 움직이는 GIF 배너를 부드럽게 재생
- 이미지 파일(.gif)이 없을 경우: 수제 제작된 실시간 웹 애니메이션 그래픽을 즉시 대체 노출

따라서 깨짐이나 에러 없이 원하시는 타이밍에 자유롭게 배너를 제작해서 채워주시면 됩니다.
